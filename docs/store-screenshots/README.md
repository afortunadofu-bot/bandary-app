# Play 商店截圖

商店截圖必須是 **App 的真實畫面**。流程：實機截圖放進 `raw/` → 跑 `compose.py` → `out/` 裡的圖上傳到 Play Console。

為什麼不能直接上傳手機截圖：Play 規定長邊不能超過短邊 2 倍，現在的手機截圖大約 1080×2340（2.17 倍），會被擋。`compose.py` 會把截圖放進 1080×1920 的畫布，上方加一句說明文字。

## 要拍的畫面

檔名照下表（開頭的編號決定上架順序、也決定配哪一句說明）。至少拍 1–5，第 6 張選拍。

| 檔名 | 畫面 | 拍的時候注意 |
|---|---|---|
| `01_shows.png` | 演唱會 →「即將到來」 | 有幾場帶海報封面的演出；最好當天有「#去年的今天」卡 |
| `02_detail.png` | 任一場演唱會詳情 | 封面大圖＋歌單（有標藝人）。**往下捲到歌單前，確認畫面上沒有取票序號、身分證、座位** |
| `03_calendar.png` | 行事曆 →「演出」月曆 | 選一個有好幾場標記的月份 |
| `04_stats.png` | 統計 →「看現場」 | 年度場次與花費大數字，下面露出一張圖表 |
| `05_events.png` | 活動 | 清單或月曆都可以，畫面上要有活動圖 |
| `06_friends.png` | 好友的日曆 或 年度排行榜（選拍） | 會出現其他人的暱稱，**只在對方同意時使用**，否則略過這張 |

## 拍攝前設定

- 淺色模式、系統字型大小維持預設。
- 開勿擾、清掉通知列，電量充飽（狀態列會被裁掉，但保險起見）。
- 用自己的真實資料，不要露出 email、取票資訊、別人的暱稱。
- **傳到電腦時用原檔**：USB、Google 雲端硬碟或「Quick Share」。不要用 LINE 或聊天軟體傳，會被壓縮。

## 產生商店圖

```
python docs/store-screenshots/compose.py
```

- 需要 Python 與 Pillow（已安裝）。
- 說明文字在 `compose.py` 最上面的 `CAPTIONS`，可以改；文字要跟畫面內容一致。
- 狀態列預設裁掉上方 3.8% 的高度；如果裁得太多或太少，改 `STATUS_BAR_RATIO`。
- 輸出在 `out/`，上傳時照檔名順序。
