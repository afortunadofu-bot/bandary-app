## 簡短說明（上限 80 字）

```
完整記錄每一場演唱會與音樂祭，掌握免費活動資訊，與好友比較年度看團場次。
```

## 完整說明（上限 4000 字）

```
Bandary（聽團曆）是一款專為現場演出愛好者設計的紀錄工具，協助你完整保存每一場
看過的演唱會與音樂祭，並掌握台灣各地的免費活動資訊。

【完整記錄每一場演出】
新增演唱會只需幾秒鐘：名稱、日期、場地、卡司、票價、座位，音樂祭亦可逐團記錄出場時間。
拍攝海報照片後，App 會自動辨識文字並帶入日期、時間、藝人名稱，確認即可，無需逐字輸入。
多日連續的音樂祭、拼盤演出、嘉賓客串皆有專屬欄位處理，完整對應現場演出的各種形式。

【檢視你的聽團歷程】
統計頁完整呈現長期累積的紀錄：總場次、總花費、看過的藝人、去過的場館與縣市、
場次成長曲線、年度與月度分布、票價區間，每一項數據皆可點入查看其組成的實際場次。

【藝人排行榜】
依場次數排序，同場次時比較花費金額、再比較追蹤時間長短，呈現具體且有依據的排名，
並可點入查看與該藝人之間的完整現場紀錄。

【免費活動資訊】
彙整台灣各地免費與售票活動，涵蓋音樂祭、市集、街頭演出，無需登入即可瀏覽。
任何使用者皆可投稿新活動，經管理員審核後公開，確保資料品質。
有興趣的活動可一鍵轉存為個人演唱會紀錄。

【每日選歌】
記錄當天在聽的歌曲，累積成個人音樂日記，並顯示連續紀錄天數。
看完演出後，也可直接從當天歌單中挑選歌曲，與該場演出的記憶連結。

【好友與年度排行榜】
新增好友後可查看彼此即將參加的演出，掌握是否會在同一天、同一場地相遇。
年度排行榜呈現本年度看團場次排名——僅公開總場次與暱稱，不會顯示紀錄內容，
亦可隨時於設定中選擇不參與排行。

【App 與網頁版資料同步】
以 Google 帳號登入，手機與網頁版共用同一份紀錄。網頁版免安裝，適合臨時查詢；
App 功能最為完整，涵蓋照片上傳、提醒通知、好友功能與 Google 日曆同步。

核心的記錄與統計功能完全免費。如需更多照片張數、深色模式、自訂主題色等進階功能，
可升級 Bandary Pro，提供買斷與訂閱兩種方案。

從今天看的這一場開始記錄，讓你的聽團足跡完整留存。
```
