# Bandary 文案語氣規範（COPY_GUIDE）

> 建立日期：2026-07-07（總規格書 Part 1-1）
> 目的：統一 App 內所有面向使用者的字串語氣，維持「安靜、克制、成熟」的雜誌編輯感，避免遊戲化、賣弄或情緒過載的用語。

## 核心語氣

- **克制、成熟、留白**：像一本安靜的手帳，而不是社群或遊戲 App。
- **描述動作，不催促情緒**：用「開賣提醒」而非「搶票提醒」；用「紀錄」而非「打卡」。
- **不使用反問句與驚嘆語氣**：例如票券即將開賣不再問「還在猶豫嗎？」。
- **中性、去性別化、去年齡化**：不假設使用者身分。

## Placeholder 規範

- 回饋輸入：`描述問題或建議…`
- 備註輸入：`輸入備註…`
- 以「…」結尾提示可繼續輸入，不用句號。

## 通知/推播

- 每日推播標題：`記錄今天的一首歌`（動作導向，不催促）。
- 開賣提醒：只描述場次與時間，不加情緒催促。

## 例外

- **程式碼註解不列入規範**：僅面向使用者的 UI 字串需遵守。原始碼註解中仍可能出現「搶票」等舊詞，屬技術脈絡用語，不影響使用者體驗。
