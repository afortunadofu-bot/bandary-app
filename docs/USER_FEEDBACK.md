# Bandary 使用者回饋與滿意度 — 專案紀錄

> 這份文件用來持續記錄「使用者怎麼看這個 App」：滿意度、評論、回報的問題與許願，
> 以及每次改版後的變化。可當作作品集 / 對外說明的佐證，也是產品迭代的依據。

## 一、資料怎麼收集（系統面）

| 來源 | 位置 | 內容 |
|---|---|---|
| **意見回饋表單** | App「我的 → 支持與回饋 → 意見回饋」；存到 Firestore `feedback` | 分類（bug / feature / other）、內容、聯絡方式（可選）、**整體滿意度 1–5 星（可選）**、email、時間 |
| **Google Play 評分** | App 內「給我們評分」導向商店 | 星等 + 文字評論（在 Play Console 看） |
| **後台彙整** | App「後台數據」 | 使用者數、活躍度、Pro 轉換率、平台內容統計 |

滿意度欄位（`feedback.rating`）已在資料模型 (`Feedback`) 與雲端 map 中就緒，送出即累積。

## 五、維護方式
- 資料來源以 Firestore `feedback`（含 rating）與 Play Console 為準。
- 每期更新第二、三、四節；第一節僅在系統變動時更新。
- 對外引用時務必**去識別化**（不放個人 email / 可辨識資訊）。
