分享海報 / 演唱會封面的內建背景圖放這裡（Batch D）。

請放 5 張演唱會背景圖，檔名固定為 bg_1 ~ bg_5，副檔名可用 webp / jpg / jpeg / png（不用轉檔）：
  bg_1.jpg   （或 bg_1.webp / bg_1.png）
  bg_2.jpg
  bg_3.jpg
  bg_4.jpg
  bg_5.jpg

建議規格：
- 直式 9:16，解析度約 1080 x 1920（分享圖輸出比例）。橫式圖也能用，顯示時會置中裁切。
- WebP（品質 ~80）最省空間；JPG 也可，每張建議壓到 200–500KB 以控制 APK 體積。

程式端：com.bandary.presentation.ui.share.PosterBackgrounds 會自動偵測這些檔案。放好後：
- 票根分享 / 統計分享的「底圖」清單會出現這 5 張，並成為預設背景。
- 新增 / 編輯演唱會的封面區會多一列「內建演唱會背景」，點一下即設為該場封面。
偵測不到檔案時沿用既有的程式繪製漸層底，不會出錯。
